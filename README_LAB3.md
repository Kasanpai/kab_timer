# Таймер кабачков — лабораторные работы №2 и №3

Это **исходный проект пользователя**, дополненный лабораторной №3. Существующие экраны и основные механики лабораторной №2 сохранены.

## Как запустить

1. Распаковать архив (внутри папка `MyApplication`).
2. Открыть **папку `MyApplication`** в Android Studio через **File → Open**.
3. Дождаться **Gradle Sync**, при необходимости подтвердить установку/выбор Android SDK.
4. Выбрать эмулятор и нажать **Run**.

Не нужно создавать новый Android-проект или переставлять стартовые Activity в манифесте.

## Переходы

- **HelloActivity** — главный стартовый экран, как в работе №2. Кнопка «Вход» открывает меню, «Регистрация» — форму регистрации.
- **MenuActivity** — старые функции «Старт», «Профиль», «Настройки», «Сообщить о проблеме», «Выход» плюс **«Пользователи»**.
- **UsersActivity** — список реальных зарегистрированных пользователей (ListView + ArrayAdapter). Кнопка **«Добавить»** открывает существующую `RegistrationActivity`; **«Назад»** возвращает в меню.
- **RegistrationActivity** — существующая форма дополнена ФИО, датой рождения, выбором пола, циклическим переключением трёх аватарок `kab.png → sun.png → nut.png`. После успешной регистрации возвращает в **список** (если вызвана из списка) или на **HelloActivity** (если вызвана с главного экрана).
- **ProfileActivity** — показывает данные последней регистрации: логин, ФИО, дату рождения, пол, аватар.
- **SettingsActivity** — переключает день/ночь; выбор темы сохраняется в SharedPreferences.

Счётчик «Выращено кабачков» остался на экранах и продолжает увеличиваться при создании Activity, включая поворот устройства. Номер передаётся между Activity через Intent и при пересоздании сохраняется в Bundle.

## Данные пользователей

- `UserRepository.kt` — учебное локальное хранилище нескольких пользователей в `SharedPreferences` с JSON-массивом.
- `UsersActivity.kt` — использует `ArrayAdapter<String>` и отдельную XML-разметку строки `item.xml`, как в ЛР №3.
- **Пользователи сохраняются после перезапуска приложения**. Повторная регистрация того же логина не допускается.
- Профиль из ЛР №2 продолжает брать данные последней регистрации из `user_data`.
- **Пароль проверяется на совпадение, но не записывается в локальное хранилище.** Вход остался демонстрационным, как в исходной ЛР №2: полноценной аутентификации в этом проекте нет.

В Logcat для лабораторной №3 используются теги `UsersActivity` и `Registration`; для жизненного цикла — `Lifecycle`.

## Что изменено

- Стартовая Activity обратно переключена с `UsersActivity` на `HelloActivity`.
- Добавлена кнопка «Пользователи» в существующее меню.
- Кнопка «Добавить» теперь открывает регистрацию вместо создания фиктивного имени.
- Регистрация добавляет пользователя в сохраняемый список и возвращается на нужный экран.
- Экран списка имеет кнопку «Назад», пустое состояние, счётчик и обработчики с Log.d().
- Сохранены существующие файлы проекта, оформление, ресурсы и Git-история в ветке `lab-3`.

**Примечание:** архив содержит исходники, не готовый APK. Сборку и запуск нужно выполнить в Android Studio на компьютере с Android SDK.
